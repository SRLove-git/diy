# 手作星球 · 移动端 UI 设计规范（v2.9）

> 设计交付：Pixso 在线设计稿（82 屏）+ 高保真 PNG 预览 + 可再生成的 HTML 源文件
> 代码交付：Flutter/Dart 工程（`app/`，82 屏页面 + 预览壳 + 资源）
>
> 设计风格：**INS 轻社交风 × iOS HIG 定制 · 黑白极简版**（简洁、年轻化，全站黑白色系，无彩色渐变）

---

## 1. 设计定位

- 客户诉求：功能简单、页面简洁、文字精简，降低学习与操作成本；按钮与图标黑白搭配、简约克制
- 风格关键词：干净、年轻、仿 Instagram、黑白、留白、卡片化、圆角、克制的功能性彩色（仅状态标签）
- 核心交互范式：底部 5 Tab（主页 / 社区 / Reels / 聊天 / 个人）+ 沉浸式信息流 + 轻弹层
- 参考页面：社区发布参考**微博发布页**；Reels 拍摄与发布参考**抖音拍摄/发布页**
- 品牌名（示例占位）：**手作星球**；品牌高光为黑白（墨色按钮/墨色胶囊/墨色描边）

## 3. 核心组件规范

- **状态栏**：62px，左侧时间「9:41」，右侧信号/Wi-Fi/电量
- **导航栏**：44px，居中标题 + 左侧返回 + 右侧操作（按钮或图标）
- **底部胶囊 TabBar**：悬浮胶囊（58px 高、28 圆角、1px 边框 + 柔和投影），5 个 Tab：主页 / 社区 / Reels / 聊天 / 个人；激活项为**墨色胶囊 + 白色图标/标签**，未激活为灰色
- **按钮**：主按钮（墨色，52px 高，16 圆角）；次按钮（表面色）；小按钮（36px 胶囊）；均为黑白
- **输入框**：表面色 52px 高、14 圆角；验证码输入带「获取验证码」操作
- **分段控件**：表面色胶囊，选中项白底浮起
- **标签/角标**：墨色/灰色功能标签 + 状态标签（红=未读/热销，绿=成功，蓝=信息）；未读红点/数字角标
- **故事环**：墨色描边 + 白色内圈 + 头像
- **互动图标**：点赞(心)、评论、收藏、分享 —— 均带计数，黑白线性
- **卡片**：白底 1px 边框 16 圆角，或表面色扁平卡
- **作品网格**：3 列无缝网格，缩略图带「♥ 计数」或「▶ 时长」角标
- **价格**：加粗主价 + 划线原价；会员价以「会员」标签区分
- **图片占位**：使用无橙色调的蓝/紫/青/绿等低饱和渐变，后续替换真实素材

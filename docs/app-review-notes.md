## 真机录屏脚本（录制前对照，避免漏项）

使用**物理真机 + 当前最新 iOS**，从桌面图标点按启动开始录（使用系统录屏功能）：

1. 冷启动 App（从图标开始，完整显示启动页）。
2. 登录页：使用 `reviewdemo` 登录（或先演示注册：用户名/邮箱/密码 → 注册完成进入首页）。
3. 首页：门店列表/精选体验入口。
4. 预约流程：选门店 → 日期/时段/人数 → 选桌位 → 确认预约 → 预约详情 + 二维码。
5. 到店核销：展示预约二维码核销页。
6. 社区：浏览信息流 → 发布图文作品（触发相册权限弹窗）→ 发布短视频（触发相机/麦克风权限弹窗）。
7. 聊天：单聊/群聊发文字 + 语音消息（触发麦克风权限弹窗）→ 展示拉黑功能。
8. 会员中心：会员套餐展示（强调到店线下支付，无 IAP）。
9. 我的：订单列表 → 设置 → 注销账号 → 输入登录密码 → 确认 → 自动回到登录页（演示应用内注销）。
10. （可选）重新登录后 → 设置 → 退出登录，单独展示退出登录流程。

录屏文件通过 App Store Connect「App 审核信息」的附件上传（或提供公开可访问的下载链接）。

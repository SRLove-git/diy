## 技术栈（已确认）

| 层级 | 选型 | 说明 |
| --- | --- | --- |
| 客户端 | Flutter 跨端框架 | 一套代码产出 iOS / Android 双端 |
| 后端 | RESTful API（Node.js） | 建议 NestJS，模块化 + TypeScript |
| 数据库 | MySQL | 持久化存储 |
| 缓存 / 会话 | Redis | 缓存、会话、分布式锁（防桌位时段超卖） |
| 管理后台 | Web 端（Vue / React） | 复用同一套后端 API |
| 部署 | Docker 化 | 开发 / 测试 / 生产三套环境 |
| 通知 | APNs + FCM / 极光·个推聚合 | App 推送；短信、邮件通道同层接入 |
| 对象存储 | 阿里云 OSS / 腾讯云 COS | 作品图片等 |

> 落地：D1 环境搭建按上表初始化（Flutter 工程 + NestJS 骨架 + MySQL/Redis 实例 + Docker Compose 三环境），后续所有排期均基于此技术栈推进。
